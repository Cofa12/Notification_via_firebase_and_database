# 📦 Notification via Firebase & Database

A Laravel package to send notifications through Firebase Cloud Messaging (FCM) and store them in the database — with a clean, scalable architecture.

---

## 🚀 Overview

This package provides a unified way to:

- Send push notifications using Firebase Cloud Messaging (FCM)
- Store notifications in your database
- Handle device tokens
- Structure notification payloads
- Decouple notification logic from your business logic

---

## ✨ Features

- 🔔 Firebase push notifications (FCM)
- 🗄️ Database notification storage
- 📱 Multiple devices per user support
- ❌ Invalid token handling
- ⚡ Queue-ready (recommended for production)
- 🧱 Clean architecture using DTOs & services
- 🔌 Easily extendable for new channels

---
